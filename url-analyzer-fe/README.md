# URL Analyzer - Frontend

This is the frontend application for the URL Analyzer project, built with [React](https://react.dev/) and [Vite](https://vitejs.dev/). It provides the user interface to submit and review analyzed URLs, communicating directly with the `url-analyzer-be` service.

## Tech Stack

* **Framework:** React
* **Build Tool:** Vite
* **Styling:** CSS / Tailwind

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) installed on your system.
